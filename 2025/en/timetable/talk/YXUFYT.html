Dress Code: How Python Writes the Future of Fashion

Dahlia 2#pyconjp_3BeginnerEN
10:30 - 11:0030min
DAY 1
09/26
FRI

Abstract

Python has grown into a key tool for creating art and fashion, moving beyond data work to help make clothing, jewelry, and interactive designs. This talk looks at how Python brings together artists, designers, and coders to build projects that mix tradition with tech. Through live coding, we'll demonstrate how libraries like Shapely, Trimesh can turn math into patterns for textiles, 3D-printed accessories, or reactive garments that light up. We'll draw inspiration from works like costumes in Black Panther or Nervous System's 3D-printed dresses, demonstrating Python's power in creating tangible art.

Description

What if your next outfit was designed by an algorithm you wrote? This talk explores how Python quietly brings together artists, coders, and makers to create wearable art that blends tradition with computation. We'll walk through how simple code - starting with basic turtle graphics - can evolve into sophisticated design tools for fashion and art. Using libraries like Shapely, numpy, matplotlib, and Trimesh, we'll live-code two projects: crafting Japanese origami-inspired fabric patterns that can be laser-cut, and creating an animated apparel design that responds to simulated heartbeat data. Watch as mathematical functions transform into intricate patterns, and see how sensor data could drive color-changing garments through visualization. We'll export real files for laser cutters and pen plotters, showing the complete path from code to fabrication. Inspired by innovators like Julia Koerner's Black Panther costumes and Nervous System's kinetic designs, the talk focuses on practical, beginner-friendly techniques. No art degree or fashion background needed - just curiosity about what happens when Python meets creativity.

Motivation

As a generative artist and creative coder myself, I've spent years exploring how Python can transcend traditional computing, particularly in the realm of tangible art and design. I've personally experimented with a wide array of tools and techniques in this space and have delivered multiple talks on similar topics, making this a passion project where I can share directly applicable insights from my own creative journey.

Key Takeaways

Attendees will gain practical knowledge on using core Python libraries such as Shapely for geometric manipulation, NumPy for numerical control, Matplotlib for powerful visualizations, and Trimesh for 3D object handling. They will learn the know-how to translate abstract mathematical concepts into concrete design patterns, create files compatible with fabrication tools like laser cutters and 3D printers, and develop logic for responsive, data-driven wearables.

Prerequisites

While the talk is beginner-friendly in its approach to generative art and fashion, no prior experience in art, fashion design, 3D graphics, or advanced mathematical concepts is required - just an eagerness to explore Python's creative capabilities.
